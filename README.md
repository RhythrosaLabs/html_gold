A collection of standalone HTML5 demos built on the [WebSim](https://websim.ai) platform. Each file is a self-contained experience — open in a browser and go. Includes 3D WebGL scenes, an AI creative studio powered by Claude and Stable Diffusion, an audio visualizer, a faithful retro Mac OS simulation, Duck Hunt, Sonic Pi in the browser, and more.

## ✨ What's Inside

- **3D Scenes** — WebGL and Three.js powered 3D models and environments
- **AI Studio** — creative suite with Claude + Stable Diffusion integration
- **Audio Visualizer** — real-time canvas-based audio visualization
- **Retro Mac OS** — faithful classic Mac OS desktop simulation
- **Classic Games** — Duck Hunt, and more browser-based retro games
- **Sonic Pi Browser** — algorithmic music composition in HTML
- **Creative Coding** — experimental canvas and WebGL experiments

## 🚀 Quick Start

Each demo is a single `.html` file:

```bash
git clone https://github.com/RhythrosaLabs/html_gold.git
cd html_gold
# Open any .html file directly in your browser
open demo.html
```

AI features require running inside [WebSim](https://websim.ai) or with your own API keys.

## 🛠️ Built With

- **Vanilla HTML5 + JavaScript** — no build step, no dependencies
- **WebGL / Three.js** — 3D rendering
- **HTML5 Canvas** — 2D graphics and audio visualization
- **WebSim** — AI model integration (Claude, Stable Diffusion)
